# student-trade-insights

Application-only mentorship site for an options and futures trading mentor and his students.

- `phase1-build-blueprint.md`: the Phase 1 spec
- `docs/PLAN.md`: the design plan and build steps for the clickable mockup
- `frontend/`: the mockup (Vite + React + TypeScript + Tailwind). See `frontend/README.md` to run it and for the demo guide.
